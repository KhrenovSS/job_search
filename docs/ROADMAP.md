# История и состояние проекта

## Текущее состояние (снимок 2026-09-20 14:00 МСК — v9.11)
- **Рефакторинг после недели v9.1–v9.10 (20.09, v9.11, решение №51)**: владелец — «проведи рефакторинг… важно, чтобы
  приложение находило работодателей для сотрудничества по ИП и чтобы бот не был заблокирован hh.ru». Три независимых
  разбора (недельный дифф, антибан, качество отбора) — итог в решении №51. Самое важное из починенного:
  метка `window.name=hh-scout-bot` (читалась страницей) заменена хендлом в kv; капча теперь **останавливает**
  подход и даёт тревогу (раньше `HHBlocked` гасился, описания открывались дальше, тревога не срабатывала никогда);
  перезапуск сервиса ночью больше не запускает сбор в 02:00 (воспроизведено на снимке kv); между сбором и
  описаниями появилась пауза, как между сериями; `sync_negotiations.py` и `hh_pages` считаются в дневном лимите;
  учёт `runs.page_loads` — сумма стадий, серия с исключением не теряет загрузки. В потоке лидов: замок между
  дайджестом и мгновенными отправками; отклик на hh.ru закрывает компанию на 90 дней, а не навсегда (все 60–75
  компаний из списка откликов были закрыты бессрочно); `/letter` по хвосту делает лид отправленным; `/stats` считает
  обе таблицы по одной зрелости и без сдвига на 3 часа; ответ редактора проходит те же проверки, что черновик,
  появилась проверка подписи и денег без валюты, правила кода вошли в `rules_hash`. В отборе: профиль владельца
  перестал говорить «вахта — не лид», из payload убраны зарплата и `search_pass`, запрос 4 ищет Allen-Bradley/
  TwinCAT/REGUL/ТЕКОН, 👎 получил «✍️ своими словами». Тесты: 224 passed.
- **Решения владельца 20.09**: разведка компаний через мост остаётся (читает hh.ru с того же IP); **profi.ru
  выключен** (`PROFI_ENABLED=false` — у хоста нероссийский IP, profi его блокирует); вахтовые карточки за 14 дней
  возвращены в триаж (`prefilter --requeue-reason fly_in_fly_out --days 14`); причины 👎 «зарплата»/«формат» оставлены.
- **Известные риски без решения** (только зафиксированы): `navigator.webdriver === true` во всём профиле Firefox
  с `--marionette` (проверено 20.09 в консоли hh.ru); нероссийский IP хоста при листании hh.ru; `document.referrer`
  на hh.ru пуст даже при переходе из страницы через `location.assign` (проверено 20.09, две страницы) — переход
  оставлен: он идёт из страницы, как у человека, а Referer, видимо, режет сама hh.
- **Проверить на первых подходах после рестарта (0-v9.11)**: в журнале подхода — «Пауза перед следующей стадией»
  между `[сбор]` и `[описания]`; `Отклики, страница 1..3`; `/status` — «Загрузок страниц сегодня» растёт по ходу
  подхода (сумма стадий); в 12:00 — дооценка пропущена, если подход идёт («Идёт подход — дооценку… пропускаю»);
  `/stats` — шапка «(письма старше 5 дн.)» и колонка «пригл.» в разрезах; 👎 → «✍️ своими словами» → ответ → строка
  карточки с причиной.
