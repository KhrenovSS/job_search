## Уроки
- Фоновые задачи из сессии Claude Code убивает её сторож памяти — долгие прогоны только `setsid`/systemd.
- Стоп-слова матчить по началу слова («водитель» ≠ «руководитель»).
- Первый вариант весов (деньги/формат) скрывал лучшие лиды — критерии должны следовать цели владельца, а не резюме.
- `.env` для systemd: комментарии только отдельными строками.
