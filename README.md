# HH-Scout

Персональный ИИ-агент для инженера, работающего по ИП. Каждый день находит на hh.ru **лиды** — компании, которым прямо
сейчас нужен программист ПЛК/SCADA, — оценивает их через Claude и присылает в Telegram карточку лида вместе
с готовым текстом отклика. Вакансия здесь не «работа, куда идти», а повод предложить компании сотрудничество.

Изначально проект строился на API hh.ru, но API для соискателей закрыт. Поэтому HH-Scout ходит по сайту
**в вашем собственном, уже запущенном Firefox** под вашим логином, читает страницы «как человек» и ничего на сайте
не нажимает. Вся логика — на вашем компьютере; облачных сервисов, кроме Telegram и вашей подписки Claude, нет.

## Что делает

1. **Собирает** свежие вакансии за 2 дня по составным запросам (ПЛК, CODESYS, SCADA, АСУ ТП…) в трёх проходах:
   49 регионов европейской части России, удалёнка по всей стране, проектная работа и подработка. Заодно читает
   ваши отклики, чтобы не предлагать уже знакомые компании.
2. **Отсеивает правилами** явный шум (продажи, 1С, вахта, названия без инженерного слова).
3. **Триаж ИИ по карточкам** — решает, какие страницы стоит открывать, чтобы не тратить лимит загрузок.
4. **Читает полные описания** одобренных вакансий.
5. **Оценивает как лид**: техническое совпадение с вашим ядром, нужен ли именно программист (а не проектировщик
   или эксплуатация), удобно ли предложить подряд. Зарплата и формат работы не влияют, только показываются.
6. **Пишет отклик** на каждый лид: только факты из вашего резюме, явное предложение сотрудничества по ИП.
7. **Присылает дайджест** в 12:00: до 20 лидов, каждый — карточка с кнопками и письмо, которое копируется одним
   нажатием. Ваши оценки подмешиваются в промпт и калибруют следующие подборки. Отработанные лиды сворачиваются,
   а если вы откликнулись прямо на hh.ru — бот заметит это сам при следующем сборе.

Сбор идёт в случайное время дня короткими сериями по 3–7 страниц с паузами 10–40 минут, не больше 80 загрузок
в сутки. Это принципиально: аккаунт hh.ru ваш, и бот ведёт себя бережно.

## Пример карточки

```
1. Инженер-программист АСУ ТП — «Компания» (интегратор)
   💰 120–160 тыс. ₽ на руки · 🏢 офис · 📍 Королёв · штат
   🤝 ИП/ГПХ: возможно
   ⭐ Лид: 89/100 (техника 92 · роль 90 · лид 78)
   Что им нужно: разработка и доработка программ ОВЕН в CODESYS, экраны панелей оператора, Modbus …
   ✉️ Зацепка: предложить подряд на разработку программ ОВЕН/CODESYS и экранов панелей для шкафов управления
   https://hh.ru/vacancy/…      [👍] [👎]

✉️ Отклик для «Компания»:  <готовый текст письма>
```

## Из чего состоит

| Компонент | Что это |
|---|---|
| `src/hh_scout/` | Python-пакет: браузер (Selenium → geckodriver → Marionette), пайплайн, ИИ-шаги, Telegram-бот, планировщик |
| `bridge/` | Мост Claude: маленький FastAPI-сервис, который превращает HTTP-запрос в вызов `claude -p` под вашей подпиской. API-ключ не нужен |
| `prompts/` | Промпты триажа, оценки и письма; ваш профиль и резюме (локальные файлы, в git не входят) |
| `scripts/` | Установка: Firefox с Marionette, geckodriver, systemd-сервис, определение chat_id |
| `docs/` | Архитектура, эксплуатация (runbook), схема БД, решения, история |

Хранилище — один файл SQLite. Логи — journald. Два systemd-сервиса: `hh-scout-bridge` и `hh-scout`.

## Требования

- Linux с графической сессией и **Firefox ESR** (проверено на Debian, Firefox 140 ESR), в котором вы вошли на hh.ru.
- Python 3.12+, `virtualenv`, `pdftotext` (poppler-utils) для конвертации резюме.
- **Claude Code CLI** с активной подпиской (`claude` в PATH) — через него работает мост.
- Telegram-бот от @BotFather.
- Компьютер включён в часы сбора (по умолчанию 13:00–23:00) и в 12:00.

## Установка

0. **Личные файлы** (не попадают в git):
   ```bash
   cp .env.example .env
   cp prompts/candidate_profile.example.md prompts/candidate_profile.md   # заполнить своим профилем
   pdftotext -layout Резюме.pdf - | sed '/Резюме обновлено/d' > prompts/resume.md
   ```
1. **Окружение**:
   ```bash
   virtualenv .venv && .venv/bin/pip install -r requirements-dev.txt -e .
   ```
2. **Firefox с Marionette** (один раз): `bash scripts/setup_firefox.sh` — создаёт вашу копию `.desktop`-файла
   с флагом `--marionette`. Закройте Firefox полностью, запустите из меню, войдите на hh.ru.
   Проверка: `.venv/bin/python scripts/check_browser.py`.
3. **Мост Claude** (sudo): `bash bridge/install.sh` — ставит сервис на `:8766` и печатает токен → в `.env` как `BRIDGE_TOKEN`.
   Модель — `BRIDGE_MODEL` в `bridge/.env.bridge` (по умолчанию opus).
4. **Telegram**: токен бота → `.env` `TG_BOT_TOKEN`, затем `.venv/bin/python scripts/tg_whoami.py` и `/start` боту —
   скрипт запишет `TG_OWNER_CHAT_ID`. Бот отвечает только этому чату.
5. **Сервис** (sudo): `bash scripts/install_service.sh`, затем `journalctl -u hh-scout -f`.

Комментарии в `.env` — только отдельными строками. Все настройки (порог, веса, лимиты, окно сбора, время дайджеста)
перечислены в `.env.example`; поисковые запросы, регионы и стоп-слова — в `src/hh_scout/config.py`.

## Команды бота

`/status` — Firefox, мост, лимиты, следующий сбор · `/digest` — прислать лиды сейчас · `/crawl` — сбор сейчас ·
`/next` — когда следующий сбор · `/pause` / `/resume` — автосбор · `/skipped [N]` — что отсеяно и почему ·
`/letter <hh_id>` — переписать отклик · `/inbox` — открытые лиды («с чего продолжить») · `/done <hh_id>` — отметить
«написал» · `/cleanup [дней]` — свернуть устаревшие · `/help`.

Под каждой карточкой четыре кнопки: 👍 / 👎 (обратная связь для ИИ) и ✅ Написал / ⏸ Позже. Обработанные лиды
сворачиваются в одну строку, письмо удаляется из чата, так что лента показывает только то, что ещё ждёт вас.

## Разработка и документация

`.venv/bin/python -m pytest -q` — тесты, без сети и браузера. Точка входа для ИИ-агента и разработчика —
`CLAUDE.md`, далее `docs/OPERATIONS.md` (ручной запуск шагов, плейбук сбоев), `docs/ARCHITECTURE.md`,
`docs/DATABASE.md`, `docs/DECISIONS.md`.

## Ограничения и ответственность

Проект читает hh.ru через ваш браузер и ваш аккаунт. Он не отправляет откликов и не нажимает кнопок на сайте, но
автоматизированное чтение может противоречить правилам площадки — используйте на свой риск и не снижайте паузы.
Личные данные (профиль, резюме, токены) хранятся только локально.
