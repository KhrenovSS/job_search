# Резюме владельца (образец; реальный файл — prompts/resume.md, он в .gitignore)

`prompts/resume.md` — текст резюме, единственный источник фактов для писем-откликов (`prompts/cover_letter.md`).
Создаётся из PDF-экспорта hh.ru:

    pdftotext -layout Резюме.pdf - | sed '/Резюме обновлено/d' > prompts/resume.md

Файл читается целиком при каждой генерации письма; разделитель `---` в нём использовать нельзя.
